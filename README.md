# readjson Project

## Overview
The `readjson` project is designed to read a JSON CycloneDX Software Bill of Materials (SBOM) file generated by a Software Composition Analysis (SCA) tool. It processes the data and converts it into a format compliant with the SPDX standard.

## Project Structure
```
readjson
├── src
│   ├── __init__.py
│   ├── readjson.py
│   └── utils
│       └── __init__.py
├── requirements.txt
└── README.md
```

## Installation
To set up the project, clone the repository and install the required dependencies. You can do this by running:

```
pip install -r requirements.txt
```

## Usage
1. Place your CycloneDX SBOM JSON file in the appropriate directory.
2. Run the `readjson.py` script to read the CycloneDX file, convert the data, and output an SPDX-compliant JSON file.

## CycloneDX and SPDX Formats
- **CycloneDX**: A lightweight SBOM standard designed for use in application security contexts and supply chain component analysis.
- **SPDX**: A standard format for communicating software bill of materials information, which helps in compliance and license management.
